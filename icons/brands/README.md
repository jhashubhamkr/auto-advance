# Brand icon sources

YouTube, Instagram and GitHub: Simple Icons 16.0.0, downloaded unchanged from https://cdn.jsdelivr.net/npm/simple-icons@16.0.0/icons/ (youtube.svg, instagram.svg, github.svg). Upstream: https://github.com/simple-icons/simple-icons/tree/16.0.0. License: CC0-1.0; included in LICENSE.md. Brand names and marks belong to their respective owners.

These filled SVG paths are stored locally; popup rendering makes no CDN requests. The popup GitHub link opens the Auto Advance source repository only when clicked.
