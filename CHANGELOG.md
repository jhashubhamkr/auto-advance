# Changelog

## 0.1.0 — Initial public preview

- Automatically advance through supported YouTube Shorts and Instagram Reels.
- Configure 0–6 additional repeats, a 0.1–3 second delay, and an optional 30–120 second duration limit.
- Show a circular countdown and Watch again control; replay resets the current cycle.
- Skip recognized video ads after the same saved delay, including visible YouTube native Sponsored overlays.
- Autosave preferences locally, provide independent platform controls, and support light/dark themes.
- Follow tab switches and single-page navigation when updating toolbar/popup availability.
- Use the selected blue circled-chevron logo and retain light/dark disabled variants.
- Keep debug logs off by default, with per-context opt-in troubleshooting.
- Include public documentation, screenshots, privacy/security guidance, regression fixtures and CI.

Known limits: desktop routes only; platform layouts and ad disclosures can change. No Chrome Web Store listing yet. Live-site qualification is tracked separately from automated fixtures.
