# Security

Only the latest published release is supported. This is a small independently maintained project; no response-time guarantee is offered.

Use GitHub's **Security → Report a vulnerability** for a private report in [this repository](https://github.com/jhashubhamkr/auto-advance/security/advisories/new). If private reporting is unavailable, open an issue asking for a private contact channel without disclosing the vulnerability.

Include the affected version, impact, minimal reproduction and proposed fix if available. Do not upload cookies, credentials, private account data or browser profiles.

The extension should run only bundled code, use only its declared YouTube/Instagram host access, store preferences locally, and never transmit playback information. Unexpected network requests, executable remote content or access beyond that scope warrant investigation.
